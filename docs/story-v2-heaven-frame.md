# 《雲上之旅：天堂遊記》故事框架 v2 設計文件

日期：2026-07-12。本 repo 自 `hell-tour-game`（幽冥之旅：地獄遊記 v1.1）分支而來；引擎、玩法、計分完全沿用，只改故事外框與語氣。舊 repo 不動。

## 一、設計目標

- **風格**：大眾、親子。刑罰點到為止，重「為什麼」與「悔過之後」。
- **氛圍**：天堂白色系。全遊戲呈「白 → 暗 → 白」三段式（天堂—地府—天堂）。
- **框架**：由神仙聊起地獄的故事；玩家下地府見習一趟後回到天堂。

## 三、故事結構

1. **序章「雲上茶會」**（`prologue.json` 全新）：睡前濟公駕蓮台來接 → 喝天水 → 過南天門（齊天大聖）→ 瑤池茶會（南極仙翁、太白金星）→ 雲鏡四問（原「陽間一日」四善惡選擇，改為孩子情境：多找的錢／群組謠言／奶奶的呼喚／受傷的小貓；axes 不變 honesty/speech/filial/mercy，karmaWeight=2）→ 東華宮原靈花樹（看見掛自己名字的小樹）→ 仙翁派濟公帶玩家下地府見習。
2. **過場「蓮台下凡」**（`interlude.json` 全新）：白轉暗、「地府是學堂」的安心設定、鬼門關。
3. **十殿**（1–9 殿沿用，僅語氣微調，見下）。
4. **結局**（`hall10.json` 改寫）：孟婆亭（不在投生之列，喝不喝隨你）→ 悟性公布 → 孽鏡反照（照出雲鏡四問的回答）→ 判詞＝雲鏡映出「你的原靈花樹現在的樣子」（四結局四種樹）→ 回天令 → 南天門大聖迎接 → 瑤池盛會、講見聞 → 天亮送回家。
